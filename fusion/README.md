# 组合导航算法层（规划）

中文 | [English](README_EN.md)

当前仓库已经提供时间同步、串口协议、记录与可视化，本目录预留给后续导航解算。现阶段尚未包含可用于定位输出的 EKF 实现。

建议按以下顺序开发：

1. 定义统一状态与坐标系（建议导航系 NED、姿态四元数、WGS-84 输入）。
2. 使用 `IMU` 的 `gps_week + gps_tow_us` 驱动 100 Hz 惯导机械编排。
3. 使用 `GNSS` 的同一 GPS 时间轴完成位置/速度量测更新。
4. 加入 Allan 参数、安装角和天线杆臂补偿，形成松组合误差状态 EKF。
5. 后续扩展 F9P 原始伪距、多普勒、载波相位与 RTK 状态，形成紧组合接口。

算法输入应直接复用 [串口协议 v3](../README.md#串口协议-v3) 及工具输出的标准CSV，避免另建与采集端不一致的时间字段。
