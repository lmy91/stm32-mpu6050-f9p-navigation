# 24位置静态标定

本目录保存24组原始采集数据、MATLAB标定脚本及本次已有标定结果。

## 文件

- `calib24_static_numbered.m`：原始标定脚本。
- `calib24/01.csv` 至 `calib24/24.csv`：24位置原始IMU数据，保留采集器的21列格式。
- `calib24/calib24_result.mat`：已有MATLAB标定结果。
- `calib24/calib24_summary.csv`：已有标定汇总。

## 运行

在MATLAB中将当前文件夹切换到本目录（`calibration/24_position`），运行：

```matlab
calib24_static_numbered
```

脚本按当前工作目录读取 `calib24/`，运行后会覆盖该目录中的结果MAT和汇总CSV。脚本保留原始Windows路径写法。

位置编号：01–04为X+，05–08为X−，09–12为Y+，13–16为Y−，17–20为Z+，21–24为Z−；每组对应绕重力轴0/90/180/270度。

加速度物理量单位为m/s²，陀螺仪物理量单位为deg/h。脚本使用内置经纬度和高度计算参考正常重力，并默认剔除每段开头及结尾各10秒。

静态24位置数据用于加速度计确定性误差标定和陀螺仪静态零偏诊断；没有已知角速度激励，不能据此可靠标定陀螺仪比例因子及非正交误差。

本次上传保留原始数据、代码与已有结果，未重新运行MATLAB计算。
