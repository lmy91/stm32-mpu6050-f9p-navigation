# 历史分步脚本

这些文件是最初对 2026-09-23 实验进行下载、合并、服务器目录诊断的分步实现，保留原始实验日期和路径约定，仅作参考。现已由上一级 `wuh2_download_merge.py` 统一替代。

日常使用请双击上一级 `run_gui.bat` 或 `run_download.bat`，无需运行这里的脚本。

- `download_wuh2_1s.py`：旧下载与解压转换流程。
- `merge_verify_wuh2.py`：旧合并和校验流程。
- `check_cddis_availability.py`：旧服务器目录诊断，直接执行会访问服务器，需要进程环境内的登录信息。
