# WUH2 1秒数据获取流程

双击 `run_gui.bat` 打开 Qt 界面；`run_download.bat` 为一键脚本。当前统一后端入口是 `wuh2_download_merge.py`，所有相关代码放在 `tools/station_observation_downloader/`。详细用法见 [工具说明](README.md)。

## 一键执行

在脚本目录运行：

```powershell
python .\wuh2_download_merge.py "C:\你的数据目录\rover.obs"
```

程序从流动站 RINEX 3 观测文件读取 GPS 日期和首尾时刻，定位 NASA CDDIS 的 WUH200CHN 高频归档。完整全天文件已存在时直接复用，不访问服务器、不再下载，也不要求输入账号。需要补充数据时才在本地提示 Earthdata 账号和隐藏密码。

## 数据来源和命名

正确地址：

https://cddis.nasa.gov/archive/gnss/data/highrate/2026/266/26d/

通用路径为 `archive/gnss/data/highrate/YYYY/DDD/YYd/HH/`，不要遗漏 `data/` 层级。

例如 `WUH200CHN_R_20262660245_15M_01S_MO.crx.gz` 中，`15M` 为文件覆盖15分钟，`01S` 为1秒采样，`MO` 为混合系统观测；先解gzip，再用CRX2RNX转换，之后用GFZRNX合并。脚本自动执行这些步骤。

首次下载需要注册/登录 https://urs.earthdata.nasa.gov/ ，并按网站要求完成CDDIS授权。密码不必发送到聊天，也不会写入脚本。

## RTKLIB 使用

Rover选择当前 `rover.obs`；Base选择时间匹配后的 `WUH2_20260923_024615_030626_1s.rnx`；导航文件可使用原目录已有的 `brdc2660.26p/BRDC00IGS_R_20262660000_01D_MN.rnx`。

MATLAB `test.m` 仍读取已解算的 `gnss.csv`，原始基站观测用于独立的RTKLIB后处理。
