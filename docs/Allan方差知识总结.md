# MPU6050 Allan 方差知识总结

本文汇总当前项目中已经讨论过的 Allan 方差相关问题，并给出与当前 MPU6050 采集配置对应的解释、参数提取方法和 GNSS/INS 滤波器使用建议。

## 1. 当前实验系统

### 1.1 硬件与采集方式

| 项目 | 当前配置 |
|---|---|
| MCU | STM32F103C8T6 |
| IMU | GY-521 / MPU6050 |
| I2C | PB6=SCL，PB7=SDA，100 kHz |
| 数据就绪中断 | MPU6050 INT → STM32 PA1/TIM2_CH2 |
| GNSS 秒脉冲 | F9P TP → STM32 PA0/TIM2_CH1 |
| 上位机串口 | USART1 PA9 → USB-TTL RXD，460800 8N1 |
| 采样触发 | MPU6050 `DATA_RDY` 硬件中断 |
| FIFO | 当前未启用 |
| 输出格式 | 串口协议v3；21列标准IMU CSV |

当前程序不是由 STM32 定时器主动读取，也不是在主循环中持续轮询。MPU6050 每产生一帧新数据，就通过 INT 引脚通知 STM32：

```text
MPU6050 产生新数据
        ↓
INT 引脚锁存为高电平
        ↓
TIM2_CH2 硬件锁存 DATA_RDY 上升沿
        ↓
TIM2 捕获中断记录与 PPS 同时钟域的微秒时间戳
        ↓
主循环读取 INT_STATUS 清除中断
        ↓
I2C 连续读取 14 字节数据
        ↓
UART 输出到电脑
```

实测结果：

```text
估计采样率：99.844 Hz
检查帧数：321
采样序号：连续，无跳变
dt_s：主要为 0.010 s；同时保留 `timer_us`、`gps_week`、`gps_tow_us` 与 `time_valid`
```

PA1 使用内部下拉输入。PA0 的 F9P PPS 与 PA1 的 DATA_RDY 都由 TIM2 输入捕获，避免软件中断到达延迟直接污染二者的相对时间。

### 1.2 当前量程和滤波配置

```text
CONFIG        = 0x03
SMPLRT_DIV    = 9
陀螺仪量程   = ±250 °/s
加速度计量程 = ±2 g
陀螺仪 DLPF  = 约 42 Hz
加速度计 DLPF= 约 44 Hz
最终输出频率 = 100 Hz
```

## 2. MPU6050 内部采样频率

当前 MPU6050 的内部信号处理速率与最终输出速率不是同一个概念。

开启 DLPF 后：

```text
陀螺仪内部输出基准：1 kHz
加速度计输出速率：1 kHz
```

最终传感器寄存器更新频率为：

```text
Sample Rate = Gyroscope Output Rate / (1 + SMPLRT_DIV)
            = 1000 / (1 + 9)
            = 100 Hz
```

因此当前链路是：

```text
MEMS 敏感结构和 ADC
        ↓
内部数字低通滤波 DLPF
        ↓
1 kHz 内部数据流
        ↓
SMPLRT_DIV 分频
        ↓
100 Hz 寄存器更新和 DATA_RDY 中断
```

`SMPLRT_DIV=9` 不是简单地将 10 个样本做算术平均。DLPF会在降采样前执行低通滤波，而分频器决定每隔多少内部时刻更新一次输出寄存器。

如果需要真正的“1 kHz读取、10点等权平均、100 Hz输出”，应由 STM32 以 1 kHz 获取数据并自行累加平均。这会显著增加 I2C 和处理负载，而且箱形平均的频率响应不一定优于 MPU6050 内部 DLPF。

## 3. DLPF 带宽

DLPF 是 Digital Low-Pass Filter，即数字低通滤波器。带宽表示传感器能够较好保留的运动频率范围。

当前配置：

```text
陀螺仪带宽：约 42 Hz
加速度计带宽：约 44 Hz
输出采样率：100 Hz
奈奎斯特频率：50 Hz
```

其效果可以理解为：

```text
缓慢变化、低频运动 → 基本保留
快速振动、高频噪声 → 逐渐衰减
```

标称 42 Hz 带宽通常表示在约 42 Hz 处，幅值下降到低频幅值的约 70.7%，即 `-3 dB`。它不是一道理想砖墙，超过 42 Hz 的信号不会立即变成零，而是被逐渐削弱。

带宽选择的基本权衡：

| DLPF 带宽 | 优点 | 代价 |
|---|---|---|
| 较高 | 动态响应快、延迟小 | 输出噪声和振动更多 |
| 较低 | 输出平滑、噪声较小 | 动态响应变慢、延迟增加 |

100 Hz 采样的奈奎斯特频率是 50 Hz。当前约 42/44 Hz 的 DLPF 在降采样前削弱高频成分，可以降低混叠风险。

Allan 标定时必须记录 DLPF 配置。改变带宽会改变曲线短平均时间区域和测得的单点噪声，因此标定配置最好与最终惯导运行配置一致。

## 4. 量化噪声

量化噪声是连续物理量被转换为有限数字刻度时产生的取整误差。

### 4.1 当前加速度计量化步长

MPU6050 是 16 位有符号输出。加速度计量程为 `±2 g`：

```text
量化步长 = 4 g / 65536
         = 1/16384 g
         ≈ 61 µg/LSB
         ≈ 0.000599 m/s²/LSB
```

### 4.2 当前陀螺仪量化步长

陀螺仪量程为 `±250 °/s`：

```text
量化步长 = 500 °/s / 65536
         = 1/131 °/s
         ≈ 0.00763 °/s/LSB
```

理想量化误差位于 `-0.5～+0.5 LSB`。若近似为均匀随机分布，其标准差为：

```text
σ_quantization = 1 LSB / √12
```

| 传感器 | 量化步长 | 理想量化标准差 |
|---|---:|---:|
| 加速度计 | 61 µg/LSB | 17.6 µg |
| 陀螺仪 | 0.00763 °/s/LSB | 0.00220 °/s |

DLPF 和量化噪声不是同一个概念：

```text
DLPF：决定保留哪些频率成分
量化：决定数字输出的最小刻度
```

降低 DLPF 带宽不会改变 1 LSB 代表的物理量。多点平均可能降低随机量化误差，但不能改变单次输出的数字刻度。

当前 MPU6050 实测陀螺仪单点标准差约为 `0.03～0.05 °/s`，明显大于理想量化标准差 `0.00220 °/s`，因此当前主要限制来自传感器本身、模拟电路、环境和振动噪声，而不是量化噪声。

## 5. 白噪声带宽

白噪声带宽表示传感器白噪声能够通过整个测量链路的有效频率范围。它不是采样率，也不是 Allan 横轴上的平均时间。

白噪声通常用噪声密度描述：

```text
陀螺仪：°/s/√Hz，rad/s/√Hz
加速度计：µg/√Hz，m/s²/√Hz
```

噪声密度、有效噪声带宽和输出 RMS 噪声近似满足：

```text
σ_RMS ≈ Noise Density × √(Effective Noise Bandwidth)
```

例如噪声密度为 `0.01 °/s/√Hz`：

```text
42 Hz 带宽：σ_RMS ≈ 0.01 × √42 = 0.0648 °/s
10 Hz 带宽：σ_RMS ≈ 0.01 × √10 = 0.0316 °/s
```

因此带宽越宽，进入输出的白噪声越多；带宽越窄，输出越平滑。

标称 `-3 dB` 带宽不严格等于有效噪声带宽。准确有效噪声带宽需要对滤波器幅频响应的平方进行积分。MPU6050没有公开完整内部滤波器系数，因此工程上通常记录标称 DLPF 带宽，并让标定配置与实际使用配置一致。

## 6. Allan 曲线斜率与误差类型

在横轴为平均时间 `τ`、纵轴为 Allan 偏差的双对数图上，常见斜率如下：

| 斜率 | 常见误差类型 | 主要时间区域 |
|---:|---|---|
| `-1` | 经典惯性器件模型中的量化效应 | 极短时间 |
| `-1/2` | 白噪声，陀螺仪 ARW / 加速度计 VRW | 短时间 |
| `0` | BI，零偏不稳定性 | 中等时间 |
| `+1/2` | RRW，速率随机游走 | 长时间 |
| `+1` | Rate Ramp，线性漂移 | 很长时间 |

实际低成本 MEMS 的各类误差会叠加，因此不一定出现教科书式的完整五段直线。参数应在局部斜率稳定的区间拟合，不应只取某一个点。

## 7. ARW 和 VRW

### 7.1 含义

ARW（Angle Random Walk）表示陀螺仪角速度白噪声积分后造成的角度随机游走。

VRW（Velocity Random Walk）表示加速度计白噪声积分后造成的速度随机游走。

在 Allan 曲线上：

```text
σ(τ) ∝ 1/√τ
```

即斜率约为 `-1/2`。平均时间增加 4 倍，Allan 偏差约下降到一半。

### 7.2 提取

在局部斜率接近 `-1/2` 的区域：

```text
N = σ(τ)√τ
```

应对整个 `-1/2` 区域计算并取中位数或进行对数线性拟合，而不是机械使用第一个 Allan 点。

若纵轴使用 `°/s`、横轴使用秒，则 `N` 的单位为 `°/√s`。转换为 `°/√h` 时乘以 60。加速度计同理，但必须严格跟踪单位。

## 8. BI：零偏不稳定性

### 8.1 含义

BI（Bias Instability）表示传感器完全静止且外界条件基本稳定时，零偏仍会在一定范围内缓慢、无规律地起伏，并且不能通过无限延长平均时间完全消除。

需要区分：

```text
固定零偏：当前静止均值偏离零多少，可以通过均值扣除
BI：扣除固定均值以后，零偏还会在附近缓慢晃动多少
```

当前曾测得的陀螺仪静态均值约为：

```text
X：-8.19 °/s
Y：-2.28 °/s
Z：-1.62 °/s
```

这些是当前开机静态零偏，不是 BI。必须先扣除平均值，再通过长时间 Allan 曲线估计 BI。

### 8.2 Allan 特征和提取

BI对应斜率接近 0 的平台或最低区域。对于理想闪烁噪声模型：

```text
B ≈ σ_plateau / 0.664
```

建议：

1. 计算 Allan 曲线局部斜率。
2. 选择斜率最接近 0 的一段。
3. 对该段的 `σ(τ)/0.664` 取中位数。
4. 不要只取一个最低点。

## 9. RRW：速率随机游走

### 9.1 含义

RRW（Rate Random Walk）表示角速度零偏本身受到持续的随机扰动，随着时间像随机行走一样逐渐漂移。

连续模型：

```text
db(t)/dt = w_b(t)
```

离散模型：

```text
b(k+1) = b(k) + w_b(k)
```

RRW使零偏方差随时间增长：

```text
Var[b(t)] ∝ t
Std[b(t)] ∝ √t
```

角速度零偏再经过一次积分后，姿态角误差可大致按 `t^(3/2)` 增长，因此 RRW 对长时间纯惯导非常不利。

### 9.2 Allan 特征和提取

RRW区域斜率为 `+1/2`：

```text
σ_RRW(τ) = K√(τ/3)
```

因此：

```text
K = σ_RRW(τ)√(3/τ)
```

应在局部斜率稳定接近 `+1/2` 的整个区间计算 `K`，再取中位数或拟合值。

必须保持单位一致。例如纵轴为 `°/s`、横轴为秒时，`K`的单位为：

```text
(°/s)/√s
```

## 10. BI 与 RRW 的核心区别

| 项目 | BI | RRW |
|---|---|---|
| 中文 | 零偏不稳定性 | 速率随机游走 |
| 典型统计来源 | 近似 `1/f` 闪烁噪声 | 白噪声积分形成的随机游走 |
| 零偏表现 | 在一定尺度附近缓慢起伏 | 长期可能不断随机走远 |
| Allan斜率 | 约 `0` | `+1/2` |
| 随时间趋势 | 平台、最低区域 | 标准差按 `√t` 增长 |
| 主要滤波用途 | 初始协方差、稳态波动尺度 | 零偏过程噪声 |

最简洁的理解：

```text
BI：零偏通常会晃动多大
RRW：零偏每单位时间被随机推动得多快
```

## 11. `+1` 斜率：Rate Ramp

Allan曲线中稳定的 `+1` 斜率通常对应 Rate Ramp，即角速度或加速度零偏随时间近似线性变化：

```text
b(t) = b0 + R·t
```

其 Allan 偏差满足：

```text
σ_Ramp(τ) = |R|τ/√2
R = √2·σ(τ)/τ
```

它通常不是随机白噪声，而是确定性或准确定性趋势。低成本 MPU6050 的常见原因包括：

- 上电自热；
- 环境温度持续变化；
- 电源电压缓慢变化；
- PCB或工装应力释放；
- 加速度计姿态缓慢改变；
- 器件老化。

RRW 和 Rate Ramp 的区别：

```text
RRW：随机方向慢慢走，Allan斜率 +1/2
Ramp：一段时间沿固定方向变化，Allan斜率 +1
```

当前数据已经保存 `temp_raw`。若长周期出现 `+1`，应首先检查温度与三轴零偏的相关性，优先建立温度补偿模型：

```text
b(T) = c0 + c1(T-T0)
```

必要时使用二次模型：

```text
b(T) = c0 + c1(T-T0) + c2(T-T0)²
```

## 12. 为什么有些低成本 IMU 的 Allan 曲线开头先上升

短平均时间处先上升通常不代表 RRW。最常见原因是 DLPF 使相邻样本相关。

理想独立白噪声从最短 `τ` 开始按 `-1/2` 下降。但滤波后相邻样本非常接近，最短 `τ` 的相邻数据块差异偏小，使最左端 Allan 偏差被压低；随着 `τ` 增加，Allan计算逐渐进入滤波器通带，曲线可能先上升，再进入正常的 `-1/2` 区域。

其他可能原因：

- 软件滑动平均或重复滤波；
- STM32读取速度高于寄存器更新速度，产生重复样本；
- 机械窄带振动形成局部鼓包；
- 数字量化码长时间不变化后突然跳变；
- 时间戳、采样周期或 Allan 公式使用错误；
- 数据重采样或插值引入相关性；
- 启动预热趋势混入数据。

判断方法：

1. 查看原始数据相邻样本自相关。
2. 比较不同 DLPF 带宽下曲线开头拐点是否移动。
3. 检查采样序号、`dt_s`、`timer_us` 和重复样本。
4. 查看功率谱是否存在窄带振动峰值。
5. 用程序生成纯白噪声，验证 Allan 算法是否得到 `-1/2` 斜率。

提取 ARW/VRW 时，应忽略被 DLPF控制的最短 `τ` 区域，寻找后续稳定接近 `-1/2` 的区间。短时间的正斜率不能直接解释为 RRW；RRW必须出现在长时间区域。

## 13. Allan 参数如何用于 GNSS/INS 滤波器

### 13.1 典型测量和零偏模型

```text
ω_m = ω_true + b_g + n_g
f_m = f_true + b_a + n_a
```

其中：

- `n_g`：陀螺仪快速测量白噪声；
- `n_a`：加速度计快速测量白噪声；
- `b_g`：陀螺仪零偏；
- `b_a`：加速度计零偏。

Allan 参数的推荐分工：

| Allan参数 | GNSS/INS中的主要用途 |
|---|---|
| ARW | 陀螺仪测量白噪声密度 |
| VRW | 加速度计测量白噪声密度 |
| BI | 零偏初始协方差、稳态波动尺度 |
| RRW | 零偏状态过程噪声 |
| Rate Ramp | 温度模型、漂移率状态或趋势补偿 |
| 静态均值 | 当前开机零偏初始值 |

### 13.2 RRW用于零偏随机游走过程噪声

采用：

```text
b_g(k+1) = b_g(k) + w_bg(k)
```

如果 Allan 提取的 RRW 系数为 `K`，且单位体系与滤波器一致，则采样周期 `dt` 下：

```text
σ_bg_step = K√dt
Q_bg = K²dt
```

当前系统：

```text
dt = 0.01 s
```

三轴离散协方差：

```text
Q_bg = diag(Kgx²dt, Kgy²dt, Kgz²dt)
Q_ba = diag(Kax²dt, Kay²dt, Kaz²dt)
```

不要忘记把 `°` 转成 `rad`，把 `g` 转成 `m/s²`，并统一秒和小时单位。

### 13.3 BI不能直接当作过程噪声Q

错误示例：

```text
Q_bg = BI²
Q_bg = BI²dt
```

BI只描述零偏波动尺度，没有描述这种变化每秒发生多快，因此仅靠 BI 不能唯一确定过程噪声。

BI可用于设置初始零偏协方差：

```text
P0_bg = diag(BIgx², BIgy², BIgz²)
P0_ba = diag(BIax², BIay², BIz²)
```

启动静态均值估计仍有误差，因此工程上可使用：

```text
P0_bias = max(静态均值估计方差, BI²)
```

这可以避免滤波器错误地认为启动零偏已经完全准确。

### 13.4 BI用于一阶高斯-马尔可夫模型

如果希望零偏随机变化但不会无限走远，可以使用一阶高斯-马尔可夫模型：

```text
db/dt = -b/τc + w(t)
```

离散化：

```text
φ = exp(-dt/τc)
b(k+1) = φb(k) + w(k)
Q_b = σ_b²[1-exp(-2dt/τc)]
```

其中：

- `σ_b`：稳态零偏标准差，可用 BI 作为工程近似；
- `τc`：相关时间；
- `dt`：滤波周期。

BI本身不能给出相关时间 `τc`。应通过自相关函数、Allan平台时间尺度和实际滤波效果共同估计。

对于初版 MPU6050 GNSS/INS，建议先使用简单的零偏随机游走模型，由 RRW 设置 `Q_bg/Q_ba`，由 BI 设置 `P0`。模型稳定后再考虑一阶高斯-马尔可夫模型。

### 13.5 不同软件参数接口可能不同

有的软件要求输入连续时间噪声密度，有的软件要求输入每个采样点的标准差，还有的软件直接要求离散协方差。三者数值不能直接复制。

设置前必须确认接口要求：

```text
输入的是噪声密度？
输入的是标准差还是方差？
时间单位是秒还是小时？
角度单位是度还是弧度？
加速度单位是 g 还是 m/s²？
软件是否已经在内部乘以 dt？
```

## 14. 静态均值扣除与 Allan 方差

静止陀螺仪均值扣除用于去掉当前开机的确定性零偏：

```text
ω_corrected = ω_raw - mean(ω_static)
```

均值扣除不会删除：

- ARW；
- BI；
- RRW；
- 温度引起的时变零偏；
- Rate Ramp。

因此均值扣除和 Allan 标定不是替代关系：

```text
静态均值 → 当前确定性零偏初值
Allan方差 → 随机噪声和时变零偏参数
```

不要随意对正式 Allan 数据做高通滤波或线性去趋势。这样可能删除真正需要测量的长期漂移、RRW或Rate Ramp。若为了诊断额外生成去趋势曲线，应同时保留原始曲线并明确标注。

## 15. 实验要求和可信度

### 15.1 建议流程

1. 将 MPU6050 固定在刚性工装上。
2. 上电预热至少 30～60 分钟。
3. 关闭串口助手，避免占用 COM4。
4. 保持设备、线缆和桌面不动。
5. 使用稳定电源，尽量保持环境温度稳定。
6. 采集至少 6 小时，建议 12～24 小时。
7. 保存温度、采样序号和时间戳。
8. 检查丢帧后再计算 Allan 偏差。

正式采集命令：

```powershell
cd D:\Dr\algorithm\low_cost_gnss_ins
D:\anaconda\envs\allan-toolkit\python.exe tools\capture_serial.py COM4 --hours 6
```

当前 `capture_serial.py` 会在接收时直接转换并保存物理量CSV，默认文件为
`data\decoded\YYYYMMDDHHMMSS\imu.csv`，无需离线解码。

分析命令：

```powershell
D:\anaconda\envs\allan-toolkit\python.exe tools\allan_noise_identification.py `
  data\decoded\YYYYMMDDHHMMSS\imu.csv
```

### 15.2 长平均时间点的可信度

Allan曲线越靠右，可用于计算的独立数据块越少，统计置信度越低。只有最后 1～2 个点呈 `+1/2` 或 `+1`，不能可靠判定 RRW 或 Rate Ramp。

工程上建议：

- 最大使用的 `τ` 不超过总数据长度的约十分之一；
- 长周期点尽量保留至少 10 个独立数据块；
- 参数在一段稳定斜率区间拟合；
- 同时检查三个轴和温度变化；
- 必要时重复多次实验验证重复性。

### 15.3 温度漂移可能伪装成随机误差

MPU6050长时间曲线的上升可能来自：

- 真实RRW；
- 环境温度变化；
- 传感器自热；
- USB供电漂移；
- 工装应力；
- 缓慢姿态变化。

因此看到长周期上升时，应同时绘制：

```text
温度-时间曲线
三轴零偏-时间曲线
零偏-温度散点图
功率谱和自相关函数
```

## 16. FIFO 与 Allan 采集

当前 INT 直读方式已经实测达到约 100 Hz 且采样序号连续，因此暂时不需要 FIFO。

如果以后需要增强对短时阻塞的容错，可以采用：

```text
MPU6050采样 → FIFO缓存 → INT通知 → STM32批量读取
```

MPU6050 FIFO 为 1024 字节。若保存加速度、温度和陀螺仪共 14 字节一帧：

```text
1024 / 14 ≈ 73 帧
73 / 100 Hz ≈ 0.73 s
```

FIFO可抵抗约0.73秒的短时处理或串口阻塞，但不能解决电脑长期卡死或串口断开。

FIFO本身不保存时间戳。一次取出多帧时必须按照固定 100 Hz 周期重建每帧时间，不能给所有积压帧使用同一个 `millis()`，否则会破坏 Allan 分析需要的等时间隔数据。

## 17. 当前项目的推荐参数使用路线

```text
静态短时均值
    → 得到当前开机陀螺仪和加速度计零偏初值

Allan短τ、斜率−1/2
    → 提取ARW/VRW
    → 设置IMU测量白噪声

Allan中τ、斜率约0
    → 提取BI
    → 设置零偏初始协方差或高斯-马尔可夫稳态尺度

Allan长τ、斜率+1/2
    → 提取RRW
    → 设置零偏过程噪声Q

Allan很长τ、斜率+1
    → 检查温度、自热和确定性漂移
    → 建立温度补偿或漂移率模型
```

对于实际 GNSS/INS，Allan 参数应作为初始设置，而不是永远不变的绝对真值。低成本 MEMS 对温度、安装、电源和振动非常敏感，最终还应根据真实车辆或实验平台的数据对滤波参数做一致性检查和适度调节。
