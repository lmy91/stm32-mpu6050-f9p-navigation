# 2026-09-30 版本整理与使用指南

本次将本地分析工具、冻结参数、输入数据和正式结果按用途纳入当前仓库。
文件保留原有路径以维持脚本依赖，不把原始记录搬入tools，也不删除本地文件。

## 1. 两套算法不能混为一谈

| 入口 | 参数来源 | 运行环境 | 本版用途 |
| --- | --- | --- | --- |
| 电动车 `test.m` | calib24温补/标定、0930 Allan、自相关GM | MATLAB + 外部PSINS | 动态回放、实际时间传播、姿态相关Q、1 Hz KML |
| `fusion/self_aim_config.json` | 2026-09-10冻结的imu_noise参考和人工配置 | Python + Qt | 在线对准/松组合；本次不改算法或参数 |
| `compare_bias_models.m` | 0930 Allan BI/平台与RRW | MATLAB + PSINS | 历史GM/RW留出实验，不是当前自相关GM的公平对照 |
| `test_bias_random_walk.m` | 0930 Allan RRW | MATLAB + PSINS | 独立历史RW回放，不自动同步最新版test |

不能把两个历史比较脚本的图表直接解释成“最新版test的GM与RW优劣”。
本次只整理、说明及上传既有算法，没有替这些实验更换模型或重生成结果。

## 2. 下载后可直接做什么

在仓库根目录打开MATLAB，先安装并初始化PSINS（例如用本机PSINS提供的路径初始化入口）。
确认 `which glvs`、`which insupdate`、`which kfinit` 能找到工具箱函数，再执行：

```matlab
run(fullfile('data','decoded','20260923104556_电动车2','test.m'));
```

输入为该目录已发布的 `imu.csv`、`gnss.csv`。
test从相对路径读取温补、24位置标定、Allan白噪声和GM候选参数，不需要21 h原始数据。
图写入 `figs/`，KML写入 `kml/combined_navigation_1hz.kml`。
运行会关闭当前图窗、清理工作区，并覆盖同名输出，应先备份自行调整过的图和结果。

静态标定/漂移对照：

```matlab
run(fullfile('data','decoded','20260923104556_电动车2','compare_acc_calibration_static_ins.m'));
run(fullfile('data','decoded','20260923104556_电动车2','compare_drift_time_windows.m'));
```

二者是纯INS静止对照，不是动态组合定位精度验收。窗口脚本当前配置为1/10/30/60/180秒。
历史模型对比可单独运行 `compare_bias_models.m` 或 `test_bias_random_walk.m`；先阅读会话README的限制。

不需要PSINS的KML测试和缓存GM重绘：

```matlab
addpath('tools'); addpath('tools/tests');
test_position_to_kml;
gm_validate_parameters(struct('replotOnly',true));
```

## 3. 参数文件与含义

| 文件 | 用途与单位 |
| --- | --- |
| `data/calib24/temp_coeffs_raw.mat` | 原始域温补，行ax/ay/az/gx/gy/gz，列c5…c0；仅补温变项，不扣c0 |
| `data/calib24/temp_coeffs_raw.csv` | 同一系数的表格，MAT另含Tref和有效温区 |
| `data/calib24/calib24_result_tempcomp_azgxgy.mat` | 与当前温补绑定的Ca、ba及元数据，不可跨配置混用 |
| `data/allan_results/mpu_21.1h_20260930/allan_parameters.csv` | 离线test的ARW/VRW白噪声参考，不用BI/平台设置当前test的GM |
| `data/decoded/20260926005735/gm_autocorrelation/gm_parameters.csv` | 传感器轴GM稳态标准差与相关时间；加计工程单位mg、陀螺deg/h、时间s |
| `data/decoded/20260926005735/gm_validation/gm_validation_summary.csv` | 模型复核状态，必须和参数一起读 |
| `data/allan_results/imu_noise/allan_parameters.csv` | 实时Python配置的旧冻结参考，上传它并不会让配置自动加载CSV |
| `data/turn_on_bias/20260930_3run_pilot/analysis/filter_init.json` | 三轮连续通电试跑统计；不适合正式滤波初始化 |

初始零偏协方差P与GM过程噪声Q是不同参数。10秒块平均用于减少白噪声；
GM拟合按块平均传递函数修正，不直接把块序列总标准差当作连续GM标准差。
单阶GM仍未证明覆盖30～600秒和跨记录行为，短记录不能验证小时级相关时间。
反馈清零的是误差状态估计，不是实际不确定度；本次不改PSINS反馈或名义零偏模型。

## 4. 重新标定或完整GM复核

安装Python统计依赖：

```powershell
python -m pip install -r tools/requirements_temp_analysis.txt
python -X utf8 tools/allan_compare_tc_configs.py --help
python -X utf8 tools/analyze_turn_on_bias.py --help
```

MATLAB复用已发布温补、重新标定24位置输入：

```matlab
addpath('tools');
run_tempcal_sop('skipStep1',true);
```

重新拟合温补和GM还需把未上传的21 h `imu.csv` 放回
`data/decoded/20260926005735/`。
默认独立验证另需 `20260921140624/imu.csv` 和 `20260921121352/imu.csv`。
按 [温补SOP](温补标定SOP.md) 完成同域温补/标定，再运行：

```matlab
run('tools/gm_autocorrelation_analysis.m');
results = gm_validate_parameters;
```

没有独立记录时不应把跳过记录或ReadOrConfigurationError解释为“验证通过”。
重新计算分段训练结果可按 [GM_VALIDATION](../tools/GM_VALIDATION.md) 显式传入空独立记录配置。
