# 硬件接线与引脚作用详解

本文详解当前项目（STM32F103C8T6 + MPU6050 + ZED-F9P + 树莓派5）中每一根连线的引脚作用、信号方向、电平与接线要点。信息来源于 `firmware/Src/main.c` 头部注释和 `raspberry_pi5/README.md`。

## 1. 全系统接线总览

```text
外部降压模块                    STM32F103C8T6               C099-F9P
────────────                    ────────────                ────────
VADJ 5.10～5.20V ─→ 树莓派 Pin 2、4
GND ─────────────→ 树莓派 Pin 6、9
固定5V ──────────→ 5V（独立供电）       │      DC_IN ← 固定5V独立支路
公共GND ─────────↔ GND                  │      GND ↔ 公共GND

树莓派 5
────────
Pin  8 (GPIO14/TXD0) → PA10/USART1_RX  │      RX_ZED ← PA2/USART2_TX
Pin 10 (GPIO15/RXD0) ← PA9/USART1_TX   │      TP     → PA0/TIM2_CH1
Pin 29 (GPIO5)      ← TX_ZED（旁路监听）│
                                      MPU6050
                                      ────────
                                      VCC ← 3.3V（STM32 稳压）
                                      GND ↔ 共地
                                      SCL ↔ PB6/I2C1_SCL
                                      SDA ↔ PB7/I2C1_SDA
                                      INT → PA1/TIM2_CH2
```

- UART、TP 和 INT 使用 **3.3 V 逻辑电平**；I2C 的 SCL/SDA 是带上拉的 3.3 V 开漏总线。树莓派 Pin 2/4 是 5 V 电源轨，不是逻辑信号。
- 所有设备（树莓派、STM32、MPU6050、C099）的 **GND 必须全部公地**。

## 2. 电源与地

| 连线 | 方向 | 作用与要点 |
|---|---|---|
| 降压模块 VADJ → 树莓派 Pin 2、4 | → | 两根5V线并联输入；VADJ预先调到5.10～5.20V，任何时候不得超过5.25V |
| 降压模块 GND → 树莓派 Pin 6、9 | → | 两根地线并联回流，主电源不经过面包板 |
| 降压模块固定5V → STM32 5V | → | 独立支路；板载LDO再稳压到3.3V供MCU和MPU6050 |
| 降压模块固定5V → C099 DC_IN 5-12V | → | C099独立支路；不能把5V OUT/3.3V OUT当输入 |
| 降压模块 GND ↔ 树莓派、STM32、C099 GND | ↔ | 全系统公共地基准 |
| STM32 3.3V → MPU6050 VCC | → | MPU6050 由 STM32 稳压输出供电，不直接接树莓派 3.3V（保持单一稳压源） |

当前现场实测模块端约5.16V、树莓派带载端约4.91V，且系统记录过欠压/降频，说明线路仍存在约0.25V压降。这个状态只能临时调试，不是正式采集验收状态。不得继续升高VADJ补偿，应改用短粗线、可靠端子并绕过面包板，使Pi端带载电压尽量保持5.0～5.15V，重启后确认`vcgencmd get_throttled`为`0x0`。系统关机后各电源轨仍可能带电，需要彻底断电时应正常关机后关闭DCDC开关。

## 3. STM32 ↔ 树莓派：USART1（460800 8N1，调试/数据通道）

| STM32 引脚 | 方向 | 功能 |
|---|---|---|
| PA9 / USART1_TX | → 树莓派 Pin 10 (GPIO15/RXD0) | 协议 v3 数据上传：IMU、GNSS、SAT、RAWX 及状态行 |
| PA10 / USART1_RX | ← 树莓派 Pin 8 (GPIO14/TXD0) | 下行：RTCM 差分数据 + 控制命令，再由 USART2 转发给 F9P |

要点：

- **TX↔RX 必须交叉连接**（自己的发送接对方接收）。
- 460800 bit/s 下杜邦线尽量短于 20 cm，信号线靠近地线。

## 4. STM32 ↔ MPU6050：I2C1（数据总线 + 采样同步）

| MPU6050 引脚 | STM32 引脚 | 作用 |
|---|---|---|
| SCL | PB6 / I2C1_SCL | I2C 时钟线，主机（STM32）驱动，100 kHz |
| SDA | PB7 / I2C1_SDA | I2C 数据线，双向开漏（上拉电阻拉高），读六轴/温度等 14 字节 |
| INT | PA1 / TIM2_CH2 | 采样同步线：每帧新数据（100 Hz）INT 拉高（锁存）→ TIM2_CH2 硬件输入捕获上升沿，得到该帧精确采样时刻 |

要点：INT 不是普通 GPIO 中断，而是接在**定时器捕获通道**上——这是时间同步方案（见《时间同步方案总结.md》）里"IMU 样本时刻由硬件定格"的物理基础。

## 5. STM32 ↔ C099-F9P：USART2（115200 8N1）+ 1PPS

| C099 引脚 | STM32 引脚 | 方向 | 作用 |
|---|---|---|---|
| TX_ZED | PA3 / USART2_RX | → | F9P UBX 输出：NAV-PVT（导航解）、RXM-RAWX（原始观测）、NAV-SAT（天空图）、TIM-TP（时间基准） |
| RX_ZED | PA2 / USART2_TX | ← | F9P 输入：UBX 配置命令 + RTCM 差分数据（NTRIP 下行，经树莓派→USART1→STM32 转发） |
| TP | PA0 / TIM2_CH1 | → | 1PPS/TIMEPULSE：GPS 时栅格、1 Hz、100 ms 高电平、对齐整秒 TOW，硬件捕获作为 GPS 时间锚点 |
| GND | GND | ↔ | 共地 |

要点：

- C099 的 J4 只短接 **ARD** 位置（7-8 脚，ARDUINO MODE），不要同时短接 UART1/UART3，否则多个发送端同时驱动 F9P RX。
- STM32 与 F9P 之间 115200 bit/s、8N1、无流控。

## 6. 旁路监听：TX_ZED → 树莓派 GPIO5（原始 .ubx 采集）

```text
C099 TX_ZED ──┬──→ STM32 PA3 / USART2_RX
              └───────────────→ 树莓派 Pin 29 / GPIO5（当前实物直接并接）
                 可选：在该支路串联 330 Ω～1 kΩ 保护电阻
```

- 作用：旁路监听 F9P 的原始 UBX 字节流，树莓派侧存 `f9p.ubx` 原始文件（加载 `uart2-pi5` 后 GPIO4/5 成为 `/dev/ttyAMA2` 的 TXD2/RXD2，GPIO4 不接线）。
- 关键：GPIO5 只接收（监听），不向 F9P 发送任何数据。当前接线没有串联电阻，由一个 3.3 V TX_ZED 输出同时驱动 STM32 PA3 和树莓派 GPIO5 两个高阻输入；确认 GPIO5 始终处于输入模式。330 Ω～1 kΩ 串阻只是建议的支路保护，不是当前实物已经安装的器件。

## 7. ST-Link（烧录/调试，正常运行时可不接）

| ST-Link | STM32 | 说明 |
|---|---|---|
| SWDIO | SWIO | SWD 数据线（双向） |
| SWCLK | SWCLK | SWD 时钟线 |
| GND | GND | 共地 |
| RST（可选） | NRST | 复位控制 |

烧录时只能选择一种供电方式：

1. **保持DCDC固定5V供电（当前方式）**：STM32继续由固定5V独立支路供电；ST-Link只连接SWDIO、SWCLK、GND，可选连接RST，ST-Link的3.3V/5V不接。
2. **ST-Link单独供电**：先关闭并断开DCDC各输出，再确认开发板及调试器允许后，仅由ST-Link 3.3V给STM32供电，同时连接SWDIO、SWCLK、GND。

两种方式不能同时使用。若断开树莓派 5 V 又不接任何独立电源，STM32 无法烧录。

## 8. 信号方向汇总

| 类型 | 引脚 | 方向 |
|---|---|---|
| 数据出 | PA9 (USART1_TX) | STM32 → 树莓派 |
| 数据进 | PA10 (USART1_RX) | 树莓派 → STM32 |
| 数据进 | PA3 (USART2_RX) | F9P → STM32 |
| 数据出 | PA2 (USART2_TX) | STM32 → F9P |
| 时间锚 | PA0 (TIM2_CH1) | F9P TP → STM32 |
| 采样同步 | PA1 (TIM2_CH2) | MPU6050 INT → STM32 |
| I2C 总线 | PB6/PB7 | STM32 ↔ MPU6050 |

## 9. 关键注意事项汇总

1. 所有设备必须共地；信号线靠近地线，杜邦线尽量短于 20 cm。
2. UART 全部交叉连接：TX 接对方 RX。
3. C099 的 J4 只短接 ARD 位置；C099由DCDC固定5V独立支路供DC_IN，不能反向取电。
4. MPU6050 由 STM32 3.3V 供电，不直接接树莓派 3.3V。
5. DCDC给STM32供电时，ST-Link只连SWD信号和GND，不接电源线；改用ST-Link单独供电前必须断开DCDC输出。
6. GPIO5旁路监听只接收，绝不向F9P发送；当前实物直接并接，可选在该支路增加330 Ω～1 kΩ保护电阻。
7. 树莓派系统关机后5V引脚仍可能带电，需要彻底断电时关闭DCDC电源开关。
8. 树莓派必须使用两根5V和两根GND供电线；Pi主电源不通过面包板，正式采集前确认`get_throttled=0x0`。
