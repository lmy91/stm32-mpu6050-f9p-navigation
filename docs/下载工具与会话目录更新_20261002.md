# 2026-10-02 下载工具与电动车会话目录更新

本次发布增加 WUH2 观测下载工具，并按用途整理 `data/decoded/20260923104556_电动车2/`。脚本路径与结果保存路径已更新，实验计算方法和原始输入数据保持原样。

## 下载工具

入口位于 [tools/station_observation_downloader](../tools/station_observation_downloader/README.md)：

- 双击 `run_gui.bat` 使用 Qt 界面，选择或拖入流动站 RINEX 3 观测文件。
- 默认读取 GPS 日期和首尾时刻，只下载覆盖该范围的最少十五分钟分段，再合并、提取完整一秒观测。
- “下载全天观测”默认不勾选，勾选后获取 96 个分段并生成 86,400 历元全天文件。
- “同时下载当天广播星历”为独立勾选项，下载 IGS 全天混合广播星历。
- 默认输出到流动站文件所在文件夹；有效匹配时段、全天、分段和星历文件可按需复用。
- 处理中可以关闭窗口，关闭会停止任务及转换/合并子程序。完整文件保留，重启后可复用；未传完的分段会重新下载。
- 密码不写入源码、日志或缓存。CDDIS 观测下载需要 Earthdata 登录；广播星历优先使用 BKG 公共归档。

源码 ZIP 为 [tools/station_observation_downloader.zip](../tools/station_observation_downloader.zip)，解压后使用同一入口。其他电脑需安装 `requirements.txt` 中的 Python 依赖，并配置 CRX2RNX 和 GFZRNX；第三方程序不包含在包内。

根目录数据定位、SOP 同目录脚本调用、Allan 模块导入、KML 测试以及树莓派历史服务入口均已同步。已安装的历史采集服务需更新服务配置，独立生产仓库沿用自己的路径与更新 SOP。依赖清单与下载工具源码 ZIP 保留在 tools 根目录；实验数据仍在 data 内。

原始 `imu.csv`、`gnss.csv`、`rawx.csv`、`sync.csv`、`f9p.ubx`、`rover.obs` 保留在会话根目录。现有图片仍在 `figs/`、`figs_bias_*/`，轨迹仍在 `kml/`。三个对比脚本自动将新 MAT/CSV 写入对应结果子目录。

在仓库根目录的 MATLAB 中先初始化外部 PSINS，再执行：

```matlab
run(fullfile('data','decoded','20260923104556_电动车2','code','navigation','test.m'));
```

回放入口读取 `gnss.csv`，不会自动执行 RTKLIB；原始基站观测和星历用于另行进行 RTKLIB 后处理。全部入口与实验限制见 [会话说明](../data/decoded/20260923104556_电动车2/README.md)。
